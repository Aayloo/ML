## 学习原则

1. 先跑最简单的 baseline，再讨论复杂模型是否真的带来增益。
2. 预处理、特征选择和调参都必须放进交叉验证或 Pipeline 的训练边界内。
3. 时间序列按时间滚动验证；最终测试区间不参与模型选择。
4. 结果不仅看一个分数，还要看误差样本、类别代价、稳定性和数据来源。
