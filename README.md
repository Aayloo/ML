# 机器学习原理

> Machine Learning From First Principles · 从零推导与动手实现的 ML Notebook 系列

一套面向量化求职与工程实践的机器学习学习笔记：每个章节一个独立 notebook，先讲原理再动手实现，并配有数据与实战案例（金融回归、图像分类、量化因子、文本分类）。

## 学习路径

```text
00 路线图 → 01 线性回归 → 02 逻辑回归 → 03 决策树 → 04 朴素贝叶斯 → 05 支持向量机
→ 06 K 近邻 → 07 K 均值 → 08 综合案例 → 09 集成学习 → 10 PCA → 11 核方法
→ 12 特征工程 → 13 综合项目 → 14 金融回归 → 15 图像分类 → 16 量化 ML → 17 文本分类
```

## 快速开始

```bash
git clone https://github.com/Aayloo/ML.git
cd ML
pip install -r requirements.txt
jupyter notebook
```

建议 Python 3.10+。
